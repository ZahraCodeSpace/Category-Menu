# 💜 Category Menu

### A Modern & Interactive Navigation Menu

A stylish and responsive category menu built with **HTML, CSS, and JavaScript**.

Explore product categories through an elegant expandable menu with a clean layout, smooth interactions, and a beautiful purple gradient design.

## ✨ Features

- 📂 Expandable product categories
- 💻 Laptop category navigation
- 📱 Mobile category navigation
- 🎧 Headphones category
- 🎵 AirPods category
- 🔽 Interactive accordion menu
- ❌ Close button for the menu
- 🎨 Modern purple gradient design
- 💫 Smooth and clean interactions
- 📱 Responsive layout

<br/>

## 🎨 Design Highlights

- Beautiful purple and pink gradient accents
- Soft shadows and rounded corners
- Minimal and modern interface
- Clear category hierarchy
- Clean spacing and typography
- User-friendly navigation experience

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/ZahraCodeSpace/Category-Menu.git
```

Navigate to the project folder:

```bash
cd Category-Menu
```

Open the project in your code editor and run `index.html` using your browser or Live Server.
